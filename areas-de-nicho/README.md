# Áreas de Nicho — Portfólio

Projetos em bioinformática, computação quântica e robótica, usando dados públicos, simuladores e acesso gratuito a hardware.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Os dados usados são públicos e citados em cada README.
