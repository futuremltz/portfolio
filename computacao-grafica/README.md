# Computação Gráfica — Portfólio

Renderizadores, shaders e simulações: da matemática de um rasterizador na CPU até path tracing e APIs modernas como Vulkan e WebGPU.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Cada README abre com imagens ou vídeos renderizados pelo próprio projeto.
