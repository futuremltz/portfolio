# Open Source — Portfólio

Minhas contribuições para projetos open source: documentação, traduções, testes, correções de bugs e funcionalidades, além de bibliotecas próprias.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Cada pasta registra uma etapa com links para os pull requests, o contexto da issue e o que aprendi.

## Padrão de cada projeto

1. **Sobre** — qual problema resolve e por quê
2. **Demonstração** — link, prints, GIF ou vídeo
3. **Tecnologias** — e por que foram escolhidas
4. **Como reproduzir** — passo a passo
5. **Resultados e testes** — o que foi medido ou verificado
6. **Aprendizados** — o que aprendi e o que melhoraria
