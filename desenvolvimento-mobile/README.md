# Desenvolvimento Mobile — Portfólio

Apps Android e iOS, nativos e multiplataforma, com câmera, mapas, sincronização offline, IA no aparelho e publicação na loja.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Cada README traz prints, um GIF de uso e, quando publicado, o link da loja.
