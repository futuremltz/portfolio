# QA e Automação de Testes — Portfólio

Planejamento de testes, automação de API, web e mobile, testes de carga, acessibilidade, contrato e pipelines de qualidade.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Os testes rodam apenas contra projetos próprios ou sites feitos para treino de automação.
