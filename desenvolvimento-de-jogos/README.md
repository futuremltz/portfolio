# Desenvolvimento de Jogos — Portfólio

Jogos e ferramentas de jogos, de Pong a um motor 2D próprio, passando por geração procedural, IA de inimigos e multiplayer.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Os jogos jogáveis estão publicados no itch.io; cada README traz GIF de gameplay e link para jogar.
