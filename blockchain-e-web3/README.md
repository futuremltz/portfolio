# Blockchain e Web3 — Portfólio

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Todos os projetos rodam em redes de teste, sem dinheiro real. Nenhuma chave privada está no repositório.
