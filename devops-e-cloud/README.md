# DevOps e Cloud — Portfólio

Projetos de automação, infraestrutura como código, containers, Kubernetes e observabilidade, do primeiro Dockerfile a uma plataforma completa com deploy canário.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Todos os recursos de nuvem foram criados na camada gratuita e destruídos após os testes. Nenhuma credencial está no repositório.
