# Sistemas Embarcados e IoT — Portfólio

Projetos com microcontroladores e sensores, do primeiro LED piscando até firmware bare-metal, RTOS, atualização OTA e TinyML.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Cada projeto inclui esquema elétrico, lista de componentes e fotos ou vídeo do circuito funcionando.
