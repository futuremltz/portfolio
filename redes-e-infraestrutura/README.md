# Redes e Infraestrutura — Portfólio

Laboratórios de redes documentados: endereçamento, VLANs, DNS, VPN, monitoramento, roteamento dinâmico e automação de rede.

Cada projeto fica em sua própria pasta, com README próprio explicando o objetivo, as decisões técnicas, como reproduzir e o que aprendi.

> Tudo foi feito em laboratório ou na minha própria rede. Endereços públicos e senhas foram removidos das configurações.
